# Winter building roofs

Snow-covered variants of the four Northern Song roof styles, generated by editing the existing atlas with the built-in image tool. Exact prompt and source are retained here.

Rebuild: tools/build-winter-tiles.js (requires sharp).
Export: assets/tiles/32/building-roofs-snow.png, 384×192, 32 colours. The original alpha mask and coordinates are retained so compact roof pieces, corners and overhangs use existing geometry.

Winter houses and halls also activate the existing detailed facades, windows and closed doors. Snow-covered gates, perimeter walls and outdoor props remain pending. The city gate keeps its procedural rendering.

Verified using building asset checks, browser previews and remaining-tile regression checks including removed-roof collision and wall transparency.
