# Northern Song building source artwork

These are high-resolution source images from the built-in image generator. `prompts.json` records the prompts and the roof revision that removed an unwanted intermediate eave. They are retained for reproducible export, not loaded by the game.

Game-ready native PNGs, coordinate metadata and usage instructions are in `assets/tiles/BUILDINGS.md`. The production export script is `tools/build-building-tiles.js`.
