# Song Jiang style variations

Two standing turnaround studies generated with the built-in image tool. Each original contains front, left and back views. These are design candidates, not walk animations.

- **A: Classic / leaner** — angular face, longer silhouette, vertical gold trim. [Original](variant-a-original.png) · [prompt](variant-a-prompt.txt).
- **B: Gentle / softer eyebrows** — relaxed brow line, warmer eyes, softer cheeks, compact silhouette. [Original](variant-b-original.png) · [prompt](variant-b-prompt.txt).

[Compare originals](compare.html) or [compare on actual game locations](in-game.html). The in-game preview defaults to B in the tavern interior. Switch variant, direction and location with the controls.

Prepared using the [approved method](../sprite-workflow.md): retained source PNGs and colours, one shared scale per turnaround, 96 × 128 frames, unchanged logical world size, four-times-density preview buffer. No palette reduction or facial pixel repainting. The preview-only engine sheets repeat each standing pose in three columns; those repeated cells are not animation frames.
