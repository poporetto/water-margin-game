# Song Jiang Classic · Head +10% study

Built-in image-tool edit of the approved Song Jiang Classic original. The prompt requests approximately 10% greater head width and height in front, left and back views, with the body, costume and stance preserved. This is a generated proportion study, not a mathematically exact pixel transformation.

Prepared using the approved original colours and 96 × 128 cell workflow. The normalization uses the original Classic body's scale, adjusted only for source canvas resolution; it does not shrink the whole figure to compensate for the larger head. Standing design study, not an animation. The approved Classic reference remains unchanged.
